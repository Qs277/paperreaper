模型密钥

两套 Key 分开填：识图模型负责「看懂卷面」，解题模型负责「推理并调用落笔工具」。两个都走 OpenAI 兼容协议。

1 识图模型 · Vision 未配置

把试卷照片转成题目、答案行位置、括号与横线信息。推荐阿里云百炼 qwen3-vl-plus。

2 解题模型 · LLM 未配置

负责读题、推理、决定每个空写什么，并调度本地落笔工具。推荐 deepseek-chat；也可以直接复用识图模型。

Key 只保存在本机浏览器的 localStorage，不会写进项目文件；运行任务时通过本机 localhost 传给本地 Agent，用完即弃。

怎么用

  1. 填 Key。在上方分别填入识图模型和解题模型的 Key，点「保存」。
  2. 传图。主界面底部选择图片，或把图片拖进中间画布。
  3. 定要求（可选）。左栏写「只做第 1-6 题」「选择题只写字母」，点「套用要求」。
  4. 生成。点「一键作答」，智能体自动识题、解题、落笔并逐题自检，跑完弹出结果编辑窗。
  5. 微调。在编辑窗里拖动答案框、调潦草程度和墨色；点「确认位置，生成定稿」按你的布局重画（不再调模型）。
  6. 拿走。点「导出」，结果图和校准图一起下载。

它怎么工作

  • 识图：视觉模型只做忠实转写，给出题号、题型和作答行位置，不碰像素坐标。
  • 解题：语言模型负责推理与答案，逐题决定写什么。
  • 落笔：本地引擎自己找括号/横线、缩放字号、贴线书写，再回检有没有横向出界。
  • 验收：只有每一题都 ok:true 才算通过；失败会自动按漂移修正并重试，仍失败就明确报出题号。
  • 隐私：试卷图片和 Key 只在本机流转；仓库里没有任何真实 Key。
  • 仿写：右栏「一键作答」下方可导入你以前的作业照片，学习墨色、字号、工整度后再作答。
